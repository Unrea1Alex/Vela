# Приёмка Vela 0.11.0

Компилятор и инструменты собирались после каждого этапа. Матрица для
конкретных платформ описана в [PLATFORM-SUPPORT](contracts/PLATFORM-SUPPORT.md).

| Этап | Результат |
| --- | --- |
| 0.11.1 | Три поколения, 1162 нативных проверки, рабочие процессы вне цикла, типизированные задачи, отмена и реальный Unicode-ввод. [Отчёт](stage111-evidence.json) |
| 0.11.2 | Три поколения, 1162 нативных проверки, 13 сценариев HTTP/HTTPS-клиента и 9 сервера. [Отчёт](stage112-evidence.json) |
| 0.11.3 | Три поколения, 17 именованных, 19 CLI и 8 HTTP-проверок FieldDesk. Реальное окно прошло HTTPS, редактирование, отмену и закрытие. [Отчёт](stage113-evidence.json) |
| 0.11.4 | Три поколения, 1167 нативных проверок. Кэш, параллельные корни, страницы без потерь и предупреждение LSP о тестовых корнях. [Отчёт](stage114-evidence.json), [замеры](stage114-measurements.json) |
| 0.11.5 | Три поколения, 1175 нативных проверок. MSVC PDB с исходным путём, профиль, трассировка задач и callback, тесты FieldDesk с panic. [Отчёт](stage115-evidence.json) |
| 0.11.6 | Три поколения, 1178 нативных проверок, C recovery, 16 проверок ресурсов и перенесённый FieldDesk. [Отчёт](stage116-evidence.json) |

Windows x64/MSVC 19.44 проверен с полным native verify. Linux x86-64 проверен
в свежем Alpine 3.22.8 под WSL2 с GCC 14.2 и musl 1.2.5. Проверки Linux
включают восстановление из C, следующую сборку компилятора, побайтовую
сходимость C, сборку и тест ресурса, перенос и распаковку архива.

На Windows проверен запуск перенесённой поставки с системным PATH и другим cwd.
Отдельная чистая установка Windows и другие настройки DPI не проверялись.
Linux-поставка поддерживает консольный сценарий. GUI, DLL FFI и сетевые
адаптеры проверены на Windows. Сервер слушает только IPv4 loopback, HTTPS
проверен на клиенте.

Извлечённый Windows-пакет прошёл проверку SHA-256 и запуск компилятора и
FieldDesk. Поставки Vela, MCP и FieldDesk имеют отдельные архивы.
Контрольные суммы находятся в `dist/SHA256SUMS-0.11.0.txt` рабочего дерева.
Для распакованного MCP проверены установка skill и библиотек, SDK-handshake
и doctor. Комплект тестов MCP прошёл 5 групп, включая 1000 запросов.
Новая приёмка исполнения в изоляции с отдельным execution manifest
остаётся вне этой проверки архива.

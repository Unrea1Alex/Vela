# Приёмка Vela 0.8.0

Платформа проверки — Windows x64 и MSVC. Этапы 0.8.1–0.8.10 выполнены в порядке
[roadmap](ROADMAP.md). Основной native verify прошёл 990/990 без пропусков.
Три поколения компилятора собраны. Сходимость C и сборщика исходников побайтная.

Точная трассировка, срезы и циклы проверены при сборке на каждой точке,
в том числе под AddressSanitizer. Проверены лексическая очистка и FFI-корни.
200 и 1600 компиляций в одном процессе дали одинаковый пик управляемой памяти
1 075 989 байт. См. [память](MEMORY.md) и `scripts/verify-gc.ps1`.

MeasureLab прошёл 12 именованных тестов и 29 CLI-проверок. Вход с ошибкой
показывает путь до значения. Готовый executable работает без математической DLL.
Builder сохранил 401 319 байт отчёта на максимальном наборе из 3072 измерений.
Замеры фиксируют управляемый heap, а не полную память процесса.

В чистом дереве native verify повторил 990/990 без пропусков. Восстановленный
из C компилятор выдал побайтно тот же C. Native-поставка собирается с MSVC и
Windows SDK. Архивы 0.7 сохранены.

MCP 0.8 прошёл три набора SDK для анализа, настройки и протокола, включая 1000
запросов. Проверены 24 сценария выполнения, 26 сценариев изоляции и 9 сценариев
отказов. MeasureLab прошёл context/help/check/build/test/run через официальный
SDK: 12 тестов, ожидаемый код 3 при превышении бюджета, HTML остался внутри
изолированного запуска. Проверено подключение через setup и SDK. Обнаружение
tools новым чатом Codex в этой приёмке отдельно не проверялось.

[Машинный отчёт](stage08-evidence.json) содержит замеры, хеши и результаты.
Локальные архивы называются `vela-0.8.0-windows-x64.zip` и `vela-mcp-0.8.0.zip`.
Контрольные суммы находятся в `SHA256SUMS-0.8.0.txt` рядом с архивами.

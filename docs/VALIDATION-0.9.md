# Приёмка Vela 0.9.0

Платформа: Windows x64, MSVC. Нативный `vela-dev verify` прошёл 999 проверок
без ошибок и пропусков. Три поколения дали побайтно одинаковый C, сборщик
исходников достиг fixed point. Восстановленный из C компилятор выдал тот же C.
Проверка в чистой поставке повторила 999/999.

CLI, LSP и MCP используют общий индекс. Проверены затенение, generic-вызовы,
ссылки через импорт, библиотека без main, частично неверный исходник,
координаты после эмодзи и отказ при конфликте или старой ревизии.
Через LSP сделано реальное переименование `query_use → record_query_use`:
пять правок в двух файлах компилятора. Проверены несохранённые буферы и
версии. В прогоне на 200 запросов LSP: 4,35 с, рабочий набор вырос с 7,78 до
8,51 МБ, число дескрипторов осталось 107. О границах сравнения с MCP:
[RFC 0006](rfcs/0006-analysis-adapters.md).
Отдельно MCP обработал 200 семантических запросов за 23,18 с;
рабочий набор изменился с 84,85 до 83,01 МБ, дескрипторы остались на 216.
В отличие от локального LSP, MCP на каждом запросе сверяет поставку и
копирует рабочий снимок. Это замеры разных путей исполнения.

MeasureLab использует raw-строки для HTML/CSS, прошёл 12 именованных и 29 CLI
проверок. Изменение байтов демо-отчёта ограничено переносами в CSS.
Форматтер сохранил вложенный тип `Result<T, json::At<json::DecodeCause>>`,
а восемь тестов форматированного RouteAudit прошли; TSV совпал побайтно.

Выдача файлов через MCP проверена на чанках, хеше, происхождении, подмене ID,
лимитах, отмене, тайм-ауте, истечении срока, hardlink/junction и отсутствии
неявной записи. Детали — в [контракте](contracts/MCP-OUTPUT-ARTIFACTS.md).
Прошли три набора SDK с 1000 запросов и 25 отменами, 24 проверки выполнения,
26 изоляции, 9 отказов и 22 проверки экспорта. Новый сеанс Codex обнаружил
инструменты, получил 17 500 байт MeasureLab и явно запросил сохранение.
Хост записал файл после сверки SHA-256; байты совпали с нативным отчётом.
Запись из самого сеанса была недоступна в режиме только чтения.

Локальные поставки: `vela-0.9.0-windows-x64.zip` и `vela-mcp-0.9.0.zip`.
Суммы находятся в `SHA256SUMS-0.9.0.txt`.

[Машинный отчёт](stage09-evidence.json) содержит результаты и контрольные суммы.

# Приёмка Vela

Текущая [приёмка 1.0.0](VALIDATION-1.0.md) включает 1.0.2–1.0.4, исходный контракт,
совместимость, миграцию, native 1214/1214, C recovery и проверку поставок/MCP.
Предшествующая [приёмка 1.0.1a–e](VALIDATION-1.0.1.md) охватывает task groups,
кэш, общий GUI, HTTP API и сравнение enum.
Историческая приёмка полного выпуска [0.11.0](VALIDATION-0.11.md) охватывает async,
сеть, GUI, кэш, отладку и платформенную поставку. Статус этапов — в [плане](ROADMAP.md).

Отдельная историческая ревизия справки 0.7.0 описана в [отчёте](measurelab-docs-evidence.json).

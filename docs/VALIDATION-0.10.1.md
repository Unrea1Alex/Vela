# Приёмка 0.10.1 — контракты абстракций

Дата: 2026-11-05. **Этап завершён: дизайн принят и проверен.**
Рабочая версия компилятора остаётся **0.9.0**. Новая грамматика не реализована;
следующий implementation-этап — 0.10.2. Это приёмка пункта, а не релиз 0.10.

## Что зафиксировано

- [ENCAPSULATION](contracts/ENCAPSULATION.md): opt-in opaque-структуры,
  управление конструированием и private-типами, прежняя семантика копирования.
- [METHODS](contracts/METHODS.md): явный receiver по значению, владелец,
  поиск и порядок вызова, эффекты и HIR lowering.
- [INTERFACES](contracts/INTERFACES.md): номинальная идентичность,
  единственная impl в модуле типа, static bounds и будущая явная dyn-упаковка.
- [CALLABLES-EFFECTS](contracts/CALLABLES-EFFECTS.md): типы вызовов,
  effect-параметры, явные capture lists, GC roots и закрытые ресурсы.
- [EFFECTS-CAPABILITIES](contracts/EFFECTS-CAPABILITIES.md): четыре прежних
  эффекта, сервисы для подмены времени/энтропии/сети, неизменные требования FFI.
- [ABSTRACTIONS-VALIDATION](contracts/ABSTRACTIONS-VALIDATION.md): bootstrap,
  диагностики E232–E239, **36 запланированных сценариев**, бюджеты и release gates.

Обновлены RFC 0002/0004: прежние открытые альтернативы получили решения и ссылки
на конкретные контракты. Изменения ownership/GC не вводятся молча; захват/box
удерживает память, но не отменяет shared invalidation при close. ABI 1 не
получает callable/interface values автоматически. Требования новых runtime
ABI, callbacks и async остаются отдельными gate до соответствующего кода.

## Фактическая проверка

Контракты прошли три раунда независимой редактуры по
skill `write-reviewed-text`. Версия v3 принята без обязательных замечаний.
Исправлены привязка private-bound теста к нужному этапу, применимость полей
диагностик и различение проверенного тела/шаблона/специализации в query.
Builtin/extern не получают ложный статус проверенного Vela-тела.

Автоматически проверены локальные ссылки, уникальность 36 ID сценариев,
сохранение порядка 0.10.1–0.10.11 и незакрытое состояние остальных пунктов.
Зарезервированные E232–E239 не заняты текущим compiler. Количества, точные
SHA-256 проверенных документов и результаты находятся в
[stage101-evidence.json](stage101-evidence.json).

**10 проверок текущей базы прошли:**

1. Имена `opaque`, `impl`, `interface`, `dyn`, `self`, `Self` не запрещены в 0.9.
2. Прежняя публичная структура сохраняет конструирование и запись поля.
3. Неиспользуемый legacy generic остаётся с отложенной проверкой тела.
4. Вызов без необходимых эффектов отвергнут E209.
5. Не введённый эффект `time` отвергнут E206.
6. Extern без process/state отвергнут E228.
7. Будущий opaque-синтаксис пока отвергнут E100.
8. Будущий interface-синтаксис пока отвергнут E100.
9. Будущий impl-синтаксис пока отвергнут E100.
10. Собран и исполнен пример копирования структуры с общим List:
    исходный scalar `1`, scalar копии `2`, общий элемент `9`; stdout `1,2,9`.

Это проверки исходных предпосылок, **не** runtime-тесты новых конструкций.
Побайтово сверены 38 файлов с началом работы: compiler/tools sources, binary,
runtime/catalog/recovery, действующие LANGUAGE/MEMORY/ARCHITECTURE и MCP pins
не изменились. Справка quickstart/skill продолжает описывать только доступный 0.9.

## Что не выполнялось

Compiler не пересобирался, full native verify не запускался: AGENTS.md требует
для документационного этапа проверки содержания/ссылок/зависимостей. Архивы
не переупаковывались, compatibility fingerprints не обновлялись. Новый агент,
MCP-клиент, GUI, GC/callback/async-проверки будущих форм не запускались.
В roadmap они сохранены за соответствующими implementation-этапами.

Следующий шаг — A02-01–A02-06 и реализация 0.10.2, затем focused проверки,
сборка compiler и `vela-dev verify` до использования новых конструкций в selfhost.

# Удерживаемые C callbacks — контракт 0.10.9

Дизайн этапа 0.10.9 для Windows x64/MSVC. Внешняя DLL использует
синхронную точку входа из `VelaCallback`. Callback вызывается в потоке,
в котором запущена Vela. Вызов из другого потока отвергается до доступа
к managed heap. Регистрация привязана к открытому ForeignHandle того же
адаптера, которому Vela передаёт дескриптор.

## Тип и ABI

`ffi_callback_register(owner, callback)` принимает
`fn(Int) -> Int effects { state, process }`. Чистый callback и меньшие
множества эффектов допустимы. Любой extern уже требует `state, process`,
поэтому возможный синхронный вызов сохраняет объявленный потолок эффектов.
Для действий с `io` GUI-адаптер возвращает событие в обычный цикл
приложения. В callback можно передать данные, прочитанные заранее.

Успешная регистрация возвращает `CallbackHandle`. В сигнатуре extern этот
тип разрешён только в аргументах и означает `const VelaCallback *`.
В Vela он отличается от ForeignHandle. Дескриптор содержит версию 1, токен
и указатель на вызываемую функцию. Точка входа получает токен, `int64_t`
и выходной указатель на `int64_t`. Код состояния отличает успех, закрытую
регистрацию, чужой поток, предел вложенности и ошибку аргумента или среды
чисел. Выход записывается только при успехе.

## Владение и вызов

Открытая регистрация удерживает owner и окружение через нативные GC roots.
Дескриптор стабилен до выхода из процесса. Выделено до 1024 регистраций
за процесс. Повторное использование дескриптора для другой регистрации
исключено. Отмена удаляет roots и инвалидирует старый токен. Сохранённый
DLL дескриптор после отмены возвращает состояние закрытия.

Разрешены вложенные вызовы, до 32 активных callback frames. Во время
активного callback его отмена возвращает ошибку без изменения состояния.
Повторная отмена закрытого handle возвращает ошибку. Закрытие owner
требует предварительной отмены всех его регистраций, иначе операция
возвращает ошибку до вызова нативного деструктора. Runtime сохраняет
среду чисел адаптера и устанавливает среду Vela на время callback.

## Приёмка

Нативный адаптер сохраняет дескриптор, вызывает его после GC и проверяет
результат захвата. Проверяются чужой поток, повторная отмена, попытка
закрытия при активной регистрации, вызов после отмены и вложенный вызов.
Отдельные проверки фиксируют E209 для лишнего эффекта и E228 для
недопустимой FFI-сигнатуры. GUI-цикл добавляется в следующем этапе.

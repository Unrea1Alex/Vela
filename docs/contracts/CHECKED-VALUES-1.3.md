# Проверенные Text и Path в 1.3.1a

Старые `text::Text`, `text::Bytes`, `path::Path` и их операции сохраняют
публичное представление и повторные проверки на границах. Для повторной
работы с одним значением добавлены закрытые `text::CheckedText` и
`path::CheckedPath`. Владение остаётся прежним: копии хранят неизменяемую
строку Vela, срезы удерживают её backing allocation. Нет native handles,
новой мутации, заимствования или изменения tracing GC.

| Операция | Контракт |
| --- | --- |
| `text::validate(data)` | Единственная полная проверка UTF-8, в том числе над Bytes.data или legacy Text.data. NUL допустим в тексте. InvalidUtf8 хранит смещение. |
| `text::checked_data(value)` / `text::legacy_text(value)` | Неизменяемая строка или совместимая запись. Редактирование копии записи не меняет закрытое значение. |
| `text::checked_slice(value, start, end)` | Полуоткрытые байтовые границы. Отклоняет отрицательные, обратные, выходящие за строку и позиции внутри UTF-8 codepoint. Граница на конце и пустой срез допустимы. Валидный срез не сканируется повторно. |
| `path::validate(value)` | Пустой путь, ошибочный UTF-8 и NUL отклоняются в прежнем порядке. Проверка не обращается к ОС. |
| `path::checked_data(value)` / `path::legacy_path(value)` | Неизменяемая строка или совместимая запись. |
| `path::checked_absolute(value)` / `path::checked_parent(value)` | Те же правила лексического пути, платформы, Windows drive и UNC, что у прежних функций. Parent остаётся непустым. |
| `path::checked_join(base, child)` | Абсолютный child заменяет base, иначе строка `base + "/" + child`. Непустой UTF-8 без NUL сохраняется по построению. |

Конструктор Path один раз вычисляет границу лексического родителя. Срезы и
соединённые пути сохраняют инвариант по построению. При запросе их родителя
граница вычисляется по разделителям, без повторной валидации строки.

Границы, приходящие из FFI/ОС/публичных записей, проходят проверяющий
конструктор. Тип гарантирует формат строки. Он не подтверждает существование
файла, разрешения доступа, каноничность или отсутствие ссылок. Изменение
публичной legacy-записи требует повторного validate при обратном переходе.
`CheckedText` и `CheckedPath` нельзя конструировать или менять снаружи модуля.

Приёмка включает буквальные fixtures для UTF-8, NUL, Unicode, UNC/drive,
пустых и недопустимых границ, alias и конверсий. Debug profile должен показать
один `invalid_offset` после построения и 2000 безопасных операций. Обычный
профиль повторяет входы и цели [1.3.1](PERFORMANCE-1.3.md). Проверяется полный
native gate, старые API fixtures и Linux console fixture.

# Окно и модель заметки — контракт 0.10.10

Текущий исходник с 1.0.1c использует [общую GUI-библиотеку](GUI-LIBRARY.md)
и `vela-gui.dll`. Библиотека владеет callback, очередью и закрытием;
правила заметки и файлового сервиса ниже сохранены. Отчёты 0.10 исторические.

Приложение Notes использует Win32 окно, многострочное поле, кнопки загрузки,
сохранения и закрытия и строку состояния. Оно работает на Windows x64 и
собирается MSVC. Текст интерфейса и содержимое файла передаются в UTF-8.
Модель и выбор файлового сервиса находятся в Vela. Win32 DLL владеет только
окном, элементами управления и временным снимком текста.

Одна модель принимает `dyn services::FileStore`. Обычный режим читает и
публикует файл, тестовый режим использует память. Сохранение проверяет
размер и кодировку. Публикация сохраняет действующий контракт атомарной
замены. Отказ отображается в строке состояния.

Окно регистрирует callback через [контракт 0.10.9](CALLBACKS.md). Он
ставит типизированное событие в очередь до 64 элементов. Блокирующее
чтение и публикация выполняются после возврата из Win32 WndProc.
Очередь обрабатывается в порядке поступления событий. Закрытие завершает
цикл, отменяет callback и освобождает окно. Повторное открытие создаёт
собственный handle и регистрацию.

Приёмка проверяет фактический вид окна, ввод Unicode, сохранение и
загрузку, отказ с видимым состоянием, три цикла в одном процессе,
закрытие процесса и отсутствие дисковых действий в тестовом режиме.
Управление окном проходит через User32. Компилятор и его bootstrap
сохраняют прежние зависимости.

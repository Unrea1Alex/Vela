# Приёмка 0.10.2–0.10.3

Рабочая сборка: **Vela 0.10.0-dev.3**, Windows x64/MSVC.

| Пункт | Проверено |
|---|---|
| 0.10.2 | Opaque-типы, граница модулей, private-поля, generic-конструкторы, копирование, трассировка скрытых значений и замена layout с relock. Native verify: 1021/1021. |
| 0.10.3 | Методы struct/enum/distinct, generic-владелец, вызов через точку и имя типа, порядок вычисления, ранний `?`, `defer`, runtime-контракты, диагностики видимости и эффектов. Native verify: 1053/1053. |

[Тест 0.10.2](../tests/cases/v102_opaque.vela) и [тест 0.10.3](../tests/cases/v103_methods.vela)
прошли с принудительным GC. Второй тест использует независимый эталон stdout:
получатель и аргументы появляются в заданном порядке, затем тело метода;
при отказе второго аргумента тело и третий аргумент не исполняются, cleanup
исполняется один раз. Скалярное поле копии меняется отдельно, вложенный список общий.

Для каждого этапа собраны три поколения, проверены compiler/bundler fixed points.
Компилятор 0.10.3 отдельно восстановлен из автономного C и побайтово воспроизвёл
свой исходный C. Тесты LSP проверили 200 запросов, привязку обоих видов вызовов к
одному объявлению, план из трёх правок, версии документов и неизменность файлов.
Тесты MCP SDK проверили те же привязки и план, совпадение версии со сборкой, а
изолированный запуск программы с opaque-типом и методом напечатал `42`.

См. [0.10.2 evidence](stage102-evidence.json) и [0.10.3 evidence](stage103-evidence.json).
Следующий этап — статические интерфейсы 0.10.4. Полный gate выпуска 0.10 впереди.

# Проверка пунктов 1.0.1a–e

Windows x64/MSVC, 2026-11-07. Все пять пунктов выполнены по порядку, с отдельным
`vela-dev.cmd verify` после каждого. Итоговый рабочий компилятор — 1.0.0-dev.5.
Это приёмка разработки 1.0.0-dev, а не выпуск стабильной 1.0.

| Пункт | Компилятор | Native verify | Результат |
|---|---|---|---|
| a | 1.0.0-dev.1 | 1180/1180 | Группы разнородных задач, await HTTP/process, владелец, отмена и cleanup |
| b | 1.0.0-dev.2 | 1185/1185 | Наблюдаемость кэша, создание каталога и fallback |
| c | 1.0.0-dev.3 | 1189/1189 | Общий GUI-слой, миграция Notes/FieldDesk/PulseDeck |
| d | 1.0.0-dev.4 | 1190/1190 | URL, методы/заголовки/Bytes, HEAD и Content-Type сервера |
| e | 1.0.0-dev.5 | 1212/1212 | Равенство одного enum без полей во всех вариантах |

Каждый завершённый gate собирает три поколения компилятора, сравнивает C побайтно,
проверяет сходимость bundler и выполняет native suite без пропусков. Сохранённые
компиляторы a–e сверены с версиями и SHA-256 в соответствующих отчётах.

Прикладные проверки:

- a: отмена активных и очередных операций, сохранение готовых результатов,
  ожидание cleanup, дочерний процесс с реальным exit 124, GC stress;
  PulseDeck — 21 HTTP/TLS-сценарий и настоящее окно с повтором/закрытием.
- b: 9 новых cache-сценариев, 9 прежних incremental/query и 4 прикладных проверки;
  установка MCP и настоящий SDK handshake с доставленными модулями.
- c: 4 lifecycle/DPI-проверки; Notes Unicode, ввод/скролл, save/load и Ctrl+A;
  FieldDesk Analyze; PulseDeck cancel/rerun/close. Видимые окна при 96/144/192 DPI
  проверены через синтетический WM_DPICHANGED.
- d: 19 клиентских и 16 серверных сценариев, включая двоичные POST/PUT/DELETE,
  HEAD с большим Content-Length и ошибки HEAD без тела, TLS, отмену и очистку
  upload-файла после неудачного запуска. PulseDeck 10+21, FieldDesk 8; GC stress.
- e: 22 изолированные проверки исходных/форматированных fixtures, точные коды
  отказа, порядок и однократность вычисления; GC stress. Исправлена доставка
  вспомогательных модулей в каталог native fixtures. PulseDeck — 11 named tests,
  21 HTTP/TLS-сценарий и реальное окно с результатом `6/6 completed | 3 healthy`.
  Установка MCP с актуальными модулями/skill, HTTP API и enum equality, сохранение
  чужой конфигурации и настоящий SDK handshake прошли на итоговом компиляторе.

Границы приёмки:

- Пул HTTP-соединений явно перенесён после 1.0: нужен постоянный транспорт
  с владением соединениями/TLS-сессиями и отдельной проверкой отмены/ресурсов.
- Linux GUI и Windows сетевые адаптеры на Linux не поддерживаются; новая
  платформенная матрица и release archives здесь не проверялись.
- Физический перенос окна между мониторами не выполнялся; DPI-события синтетические.
- MCP setup/SDK handshake не означает проверку автоматического обнаружения skill
  новым desktop-чатом; полная приёмка нового агента остаётся в 1.0.4.
- C recovery seed и архивы 0.11 сохранены. Фиксация API — 1.0.2, миграции — 1.0.3,
  новый seed/поставки и полная приёмка выпуска — 1.0.4.

# MeasureLab

Небольшой проект на Vela 0.9.0: анализ результатов измерений и автономный HTML-отчёт.
Вся модель данных, статистика, проверка JSON и генерация отчёта написаны на Vela.
Квадратный корень и форматирование чисел используют встроенные функции Vela.

## Запуск

Откройте [report.html](report.html), чтобы сразу посмотреть результат. Двойной щелчок
по [run-demo.cmd](run-demo.cmd) пересоздаёт отчёт из [sample.json](sample.json)
и открывает его в браузере. В демонстрации 3 сценария, 60 замеров и одно превышение
лимита. Данные синтетические: это не результаты измерений компилятора Vela.

В исходном репозитории сначала соберите приложение командой ниже. Для своих
данных из PowerShell, находясь в корне репозитория Vela:

```powershell
./apps/measurelab/bin/measurelab.exe input.json output.html
./apps/measurelab/bin/measurelab.exe input.json output.html --fail-on-budget
```

Для запуска достаточно `bin/measurelab.exe`.
Python, Node.js, Vela и MSVC для его запуска не нужны. Отчёт — один автономный HTML.

## Исходники и новые возможности

| Файл | Назначение |
|---|---|
| model.vela | JSON, config, UTF-8, ограничения и типизированные Result |
| statistics.vela | Float64, сортировка копии коллекции, Welford и встроенный sqrt |
| report.vela | Структуры/enum, сравнение с baseline, SVG и HTML-экранирование |
| main.vela | CLI, Path, чтение с лимитом, идентичность файлов, атомарная публикация |
| tests.vela | 12 именованных тестов, табличные случаи std.testing |
| vela-stdlib | Локальная копия модулей Vela 0.8, зафиксированная lock |

Из корня репозитория Vela:

```powershell
./apps/measurelab/build.ps1
./vela.cmd test apps/measurelab/vela.project --json
./apps/measurelab/verify.ps1
```

В отдельно распакованном проекте передайте установленный toolchain явно:
`./build.ps1 -VelaRoot G:/Tools/Vela`. Для сборки используется MSVC x64/Windows SDK. Скрипт обновляет lock и копирует готовый executable в bin.

Для подключения агента выполните setup по [инструкции MCP](../../integrations/mcp/README.md),
указав свою папку приложения и toolchain. Затем из папки приложения запустите
`node ./vela-codex.mjs`. Настройка подключения не доказывает, что старый чат обнаружил
tools. Конфигурация `.codex` и launcher с абсолютными путями не включаются в Git
или архив приложения; их нужно создать заново после переноса проекта.
`node check-mcp.mjs PATH_TO_MCP_PACKAGE` — необязательный интеграционный тест через SDK.
Он действительно проверяет изолированные build/test/run; созданный внутри MCP HTML
не экспортируется в проект. Для сохраняемого отчёта используйте нативный executable.

## Контракт

- Вход: UTF-8 JSON до 256 KiB; корневые поля `title` и `scenarios`.
- От 1 до 12 сценариев с уникальным именем; поля `name`, `unit`, `baseline`,
  `budget`, `samples`. Неизвестные и повторные поля отвергаются.
- Заголовок — до 240 байт UTF-8, имя — до 160, единица — до 24; после ASCII trim
  они непустые и не содержат управляющих байтов 0..31. Регистр имён учитывается.
- От 1 до 256 измерений в сценарии. Значения конечные, в диапазоне 0..1e9.
  `baseline` и `budget` — 1e-6..1e9. Допускаются целая и дробная записи JSON;
  преобразование Int в Float64 выполняет приложение явно и требует точного представления.
- Среднее и популяционное стандартное отклонение вычисляются алгоритмом Welford.
  Медиана — среднее двух центральных элементов при чётном размере; p95 —
  nearest rank: элемент `ceil(0.95 * n) - 1` отсортированной копии.
- Базовый уровень сравнивается со средним: `(mean / baseline - 1) * 100`.
  Предполагается метрика «меньше — лучше». Лимит сравнивается с p95, равенство допустимо.
- Весь вход проверяется до записи. Единственный HTML публикуется атомарной заменой;
  путь входа и его файловые алиасы нельзя использовать как выход.
  Ошибка cleanup после commit сообщается отдельно, автоматического повтора нет.
- CLI: `measurelab.exe INPUT OUTPUT [--fail-on-budget]`; `--help` показывает справку.
  Коды: 0 — успех, 2 — вход/CLI/I/O, 3 — отчёт сохранён, но лимит превышен
  при `--fail-on-budget`. Аргументы путей относятся к текущему рабочему каталогу.
- HTML содержит CSS/SVG внутри себя, экранирует пользовательский текст и не обращается
  к сети. Для просмотра достаточно браузера. Файлы приложения не получают автозапуск.
- Поддержанная конфигурация: Windows x64/MSVC и Vela 0.9.0. Достижимые значения
  удерживает GC. Вход и промежуточные фрагменты ограничены.

## Проверка готовности

Сборка проекта, 12 именованных тестов, 29 CLI-сценариев и отчёт без DLL.
Проверены путь ошибки JSON, лимиты, Unicode, экранирование и сохранение файла
при отказе. [Приёмка приложения](VALIDATION.json) и [приёмка Vela](../../docs/VALIDATION-0.9.md).

Приложение использует `float_sqrt`, `float_to_fixed`, JSON-курсор и builder.
HTML и CSS хранятся в raw-литералах. В изолированном MCP-запуске запросите
`outputs: ["report.html"]` и передайте аргументы
`["sample.json", "../export/report.html"]`. Получив `output_id`, скачайте
байты через `vela_read_output`, проверьте SHA-256 и сохраните их явно.
Демо-отчёт остаётся автономным. Материалы и архив MeasureLab на Vela 0.7
сохраняют исторические результаты с математическим адаптером.

# Использованные возможности Vela

FieldDesk объединяет поддержанные семейства возможностей языка в одном
приложении. Это не проверка каждого builtin и каждой допустимой формы синтаксиса.

| Возможность | Где используется | Проверка |
|---|---|---|
| Int, Float64, Bool, String, Int32 | Счётчики, калибровка, JSON, длина снимка GUI через FFI | Числовые границы, статистика, реальный экспорт |
| Структуры, enum, distinct ID | SampleId, Settings, Band, Event | Порог, очередь событий, ID в отчёте |
| Opaque и методы | Закрытые Sample/Settings, публичные методы чтения и калибровки | Клиентские модули работают без доступа к полям |
| Generics и интерфейсные ограничения | Batch<T>, transform<T,U,E>, statistics<T:Measured> | Два типа результата transform, расчёт через Measured |
| Статические интерфейсы | Measured для Sample | Среднее, диапазон, отклонение |
| Динамические интерфейсы | FileStore, Processes, Clock, Entropy, Exchange | OS, память, scripted responses, playback |
| Функции, явные захваты, эффект-параметр | Калибровка, источник байтов, обработчик события | Чистая и stateful-функции, чтение по одному байту |
| Все четыре эффекта | CLI args, файловый io, коллекции state, process/FFI | Проверка всего графа приложения |
| List, Dict, итерации и сортировка | Группы станций и порядок сводок | 32 станции, исключения, стабильный порядок |
| Result, Option, match, `?` | Декодирование, EOF, сервисные ответы | Ошибки с физической строкой и JSON-путём |
| `requires`, `ensures` | Номер записи, деление на положительное число, конечный результат | Выполняемые контракты, без заявления о статическом доказательстве |
| Raw-строки и интерполяция | HTML/CSS/JS и исходные примеры | Исполняемый отчёт, Unicode и HTML-экранирование |
| JSON, Bytes/Text, Path, builder | Лимиты JSON, проверка UTF-8, отчёт, публикация | Границы размеров, malformed input, алиасы файлов |
| Потоковый ввод | Native stream и effect-polymorphic lines reader | Совпадение stream/snapshot, BOM и CRLF |
| Подмена сервисов и replay | Весь пакетный сценарий | Повтор без записи, ошибки/порядок/неполный журнал |
| Время, энтропия и PRNG | Метаданные запуска | OS в CLI, фиксированные ответы в тестах и replay |
| Дочерний процесс | Проверка оболочки опубликованного HTML | Реальный запуск, код ошибки через mock |
| GC, scope/defer и явное close | Повторный анализ, builder, native handles | 5/40 повторов под GC, закрытие GUI и HTTP |
| FFI и удерживаемые callbacks | Win32 редактор и ограниченная очередь | Реальные действия окна, отмена перед закрытием |
| Существующий HTTP-прототип | Необязательный источник NDJSON на loopback | 200, 404, лимит, зависший ответ, отказ соединения |
| Проект, lock, fmt, query, plan | Манифест с двумя native DLL, анализ символов | Сборка, идемпотентный fmt, preview переименования |
| Именованные и табличные тесты | tests.vela | 17 тестов с явными ожидаемыми результатами |

Асинхронные задачи, await/cancellation, полноценные HTTP/TLS, переносимый GUI и
внешние resource-декларации остаются планом. JavaScript внутри отчёта отвечает
только за браузерный поиск и фильтр; расчёты и HTML создаёт Vela. C обслуживает
Win32/WinHTTP и определение пути exe. MCP-инструменты в этом клиентском сеансе
не обнаружены, поэтому использован нативный CLI. Новый MCP-клиент и LSP здесь
не проверялись; прежняя приёмка этих инструментов не считается проверкой FieldDesk.

# TimeLog — отчёт по рабочему времени на Vela

Статус: реализовано и проверено на Windows x64/MSVC, 2026-11-04.
Историческая прикладная проверка 0.5 по поручению пользователя; на тот момент
следующим этапом был 0.6.1. Текущее состояние языка — в [roadmap](../../docs/ROADMAP.md).

Приложение читает журнал времени и создаёт автономный HTML-отчёт: общее время,
итоги по проектам и список записей. Интернет и JavaScript не требуются.

```powershell
.\velac.cmd build apps/timelog/main.vela -o apps/timelog/timelog.exe
.\apps\timelog\timelog.exe apps/timelog/demo.tsv apps/timelog/report.html
```

Локальная поставка Windows x64 `dist/timelog-windows-x64.zip` не требует
компилятора. Распакуйте архив и выполните `.\timelog.exe demo.tsv report.html`
из его папки. Пример содержит 5 записей, 3 проекта и 290 минут (4 ч 50 мин).
Свой журнал можно составить по образцу `demo.tsv`; результат — `report.html`.
Архив не входит в Git; после клонирования используйте команды сборки выше.

Формат входа — UTF-8 TSV, три колонки: `project`, `minutes`, `note`; разделитель —
табуляция. Заголовок обязателен. Допускаются BOM, LF/CRLF и пустые строки.
Проект непустой, minutes — только десятичные цифры, значение от 1 до 1440.
Пустое описание допустимо. Quoting и многострочных полей нет; табуляция внутри
поля запрещена. Внешние ASCII-пробелы полей удаляются. Управляющие символы и
повреждённый UTF-8 отклоняются. Лимиты: 1 MiB входных байтов, 10000 записей.
Файл читается целиком, затем проверяется размер; это ограничение обработки,
а не потоковый предел чтения/памяти. Нужна обычная локальная доверенная среда.

Проекты выводятся в порядке первого появления, записи — в исходном порядке.
Время считается целыми минутами и отображается как часы/минуты; округления нет.
Проценты доли проекта округляются вниз до целого и могут не давать в сумме 100%.
Пользовательские поля экранируются как HTML-текст. Пустой журнал даёт пустой отчёт.

Ошибки записей содержат номер строки; 0 обозначает ошибку файла целиком
(кодировка или размер). При ошибке входа или записи старый отчёт
сохраняется. Запись выполняется через уникальную временную папку рядом с отчётом
и замену после успешной записи. После записи или отказа приложение пытается
удалить временные объекты; ошибка очистки не подменяет основной результат.
Сбой процесса или ОС может оставить временную папку; crash-durability не обещается.
Назначение, совпадающее с входным файлом (включая hard-link), отклоняется до записи.
Параллельная подмена путей другими процессами не входит в контракт.
Успех/`--help`: exit 0; ошибка аргументов, данных или I/O: exit 2.

Приёмка: сборка и одинаковый результат исходного/форматированного приложения;
точные суммы/порядок, Unicode/BOM/CRLF, пустой файл с заголовком, HTML-экранирование,
ошибки чисел/строк/кодировки/лимитов, сохранение старого отчёта, алиасы и отказ I/O.
Ожидания фиксируются в нативном стенде `tools/test.vela`.

В исторической приёмке 0.5 проверено: 58 прикладных проверок в общем стенде, 3 дополнительных сценария
файловой системы; полный `vela-dev.cmd verify` — 688/688, без ошибок и пропусков.
Структура и содержимое HTML проверены автоматически. Визуальная проверка браузером
не выполнена: инструмент отклонил локальный протокол `file://`.
